Scenario 2: confidential client, hidden iframe + leaked code

Against the confidential client demo-conf the attacker can't redeem a stolen code directly (no client_secret). Instead: /lure is a page with a hidden iframe that silently drives the victim's browser through demo-rp's /conf/login flow. The RP's callback page leaks the code to this server's /collect, which immediately forwards it to the RP's own backend to redeem - racing (and beating) the victim's own browser - and captures the legitimate session cookie the RP hands back.
